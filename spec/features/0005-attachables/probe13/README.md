# v13 — アニメーションの position と**装着者の回転**が同じ骨でどう合成されるか

**v12 が「親→子の階層は正しい」と確定させた**ので、残rulesは未測定のものだけ。
コーパスを全部読んだ結果、ホシノとシロコの唯一の構造差がここにあった。

## なぜこれが候補か（コーパスの実測、引用のみ）

| | `.hand` が **`body` / `head`**（装着者骨）に書くか |
|---|---|
| **ホシノ** | **する** — `"body": { "position": [0, -1, -6] }` |
| シロコ | **しない**（`root3` / `body3` / 両腕 / 両脚 のみ） |

そして装着者の半回転は **一人称だけ**（`FIRST_PERSON_WEARER` は一人称でだけ
`body` と `head` に `rotationY(180)` を渡す）。**「三人称は正常・一人称だけ異常」と
ちょうど一致する。**

**この合成は v9〜v12 のどのプローブも測っていない。** v9/v10 は骨1本の自分の順序、
v11/v12 は階層だけ。**アニメーションと装着者が同じ骨に書く**場合の順序は未測定。

## 読んでいる規則

本実装は `animated.times(driver)` = **`T(pos) · R(180)`**（位置が最外）。
つまり装着者の 180° を**先に**当て、その**後**に `position [0,0,-24]` を足す。
90°/180° は Z を反転させるので、順序が違えば**符号が反転**する。

## 中身

```
root
 ├ body   ← 装着者骨（一人称で R_y(180) を受ける）  …アニメーションが position を書く
 │   └ m_body  pivot [0,-8,0]  棒（X 方向、長さ 12）
 └ flat   ← 対照。装着者骨でない。アニメーションは書かない
     └ m_flat  pivot [0, 8,0]  棒（X 方向、長さ 12）
```

アニメーションは `body` の `position [0,0,-24]` **だけ**。子には何も書かない。

### 段階 1 — 三人称（**合成の未確認**。装有依らず.animation の position だけ）

| | 答え |

### 段階 2 — 一人称（**本丸**）

| | 答え |
|---|---|
| **下の棒は見えるか** | 本実装は **見える。1.5 ブロック分、画面側に浮いて出る** |

**「見えない」なら順序が逆**（装着者の回転が最外）= ホシノの原因。

−1.5 ブロックはカメラの手前、+1.5 ブロックはカメラの後ろなので、**見える / 見えない** で
完全に二分します。主観の距離判断は不要です。
