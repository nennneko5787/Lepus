# v11 — 親の変換が「子のアニメーション位置」を運ぶか

**§4.1.3（位置）は確定済み。残るは「親→子」で、区間としては一度も測られていない。**

v9/v10 が確定させたのは **骨自身の回転が骨自身の位置を運ばない**こと（probe の `pos` / `rot` /
`full` の3点比較）。今回問うのは**別物**で、v9/v10 のリグは `root2` **1本**のアニメで、
**親が回転したまま子が平行移動する**構成を一度も読んでいない。

## なぜこれがホシノの頭位移の原因候補なのか（測定）

`kivotos:hoshino_onbu` 一人称の extent から、各チャンネルを除いたときの**顔と胴体の前方差**を
WindExcept したもの（`AddonSurvey` 経由、Third person を基準）:

| 除外したチャンネル | body2 z | eye2 z | 差 |
|---|---|---|---|
| （なし） | −12.08..−3.09 | −20.47..−13.00 | **8.39** |
| `head2` の `position [8,4,0]` | −12.08..−3.09 | −11.07..−3.60 | **−1.01** |
| `head2` の `rotation [0,-25,5]` | −12.08..−3.09 | −19.56..−11.93 | 7.48 |
| `head2` の `scale 0.7` を 1.0 に | −12.08..−3.09 | −22.14..−11.47 | 10.06 |
| `root2` の `yaw −85` を 0 に | −6.78..2.02 | 4.18..7.80 | −10.96 |

**`head2` の `position [8,4,0]` だけが症状の全部**である。ここに Z は無く、X=8 だけ。
にもかかわらず一人称では前方约 9.4 units へ出る，因为它が**親 `root2` の yaw −85° に運ばれる**ため。
三人称で正常なのは、`root2` の yaw が idle の `[22.5,0,22.5]` で **0** だから。

## 中身

```
root
 ├ arm_yaw    rotation [0,90,0]        ← 変数。親が回っている
 │   └ m_yaw    pivot [0, 0, 0]        棒（X 方向、長さ 6）
 ├ arm_none                          ← 対照。親に何も無い
 │   └ m_none   pivot [0, 8, 0]        棒
 └ arm_scale                         ← 変数2。親がスケール
     └ m_scale  pivot [0, -8, 0]       棒
```

アニメーションは3本の子に**同じ** `position [8,0,0]` だけを書く。`arm_scale` には
`scale 1.5`。**子側の rotation / scale は1つも書かない** — 親が運ぶかだけを見るため。

## 手順（統合版）

1. `probe11.mcaddon` を読み込み、ワールドで **BP と RP 両方**を有効化
2. `/give @s lepus:probe11`
3. **メインハンドに持って三人称**（F5）。棒3本が横並びで見える。**一人称だと近すぎて読めない**

## 読んでほしいもの（**2 問だけ。数値は不要**）

| | 質問 | 「運ぶ」 | 「運ばない」 |
|---|---|---|---|
| **1** | **上の棒と真ん中の棒は、伸びる方向が同じか直交するか** | 直交（上の棒が Z を向く） | 平行（両方 X） |
| **2** | **下の棒は、真ん中の棒から距離 1.5 倍か、同じか** | 1.5 倍遠い | 同じ |

（本実装の予測は**両方とも「運ぶ」**。上の棒が Z を向く・下の棒が遠い。）

## どちらがкардинально问题时.diffになるか

- **1 が「運ばない」** → 親の回転は子のアニメ位置を運ばない、となる。**これが §4.1 の親‑子区間
  のバグ**で、ホシノの頭の 9.4 units はここから説明がつく。実装を直す
- **1 が「運ぶ」** → §4.1 の親‑子区間は正しい。**ホシノの原因は別にあり**、v9/v10 が既に確定させた
  骨自身の順序（`T·R·S`）か、`query.target_*_rotation` の一人称の値（SC-180 §4.2.1 の TODO）の
  どちらかに切り分け直す。**どちらの場合も v11 のデータは捨てない**（実装との一致が測れる）
