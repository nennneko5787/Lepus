# v19 — **決着にならなかった。答案是「无效」**

**この rig は `SPEC180 §4.2.4` が「次に必要な probe」と書いた対を問おうとしたものだが、
質問文と rig が別のことを聞いていた。** 実行して分かったので記録する。

## 問おうとしていたこと

**骨自身の宣言された回転**が、**自身の**アニメーション position を運ぶか — 未測定の対（盾 `bag2` がまさにこれ）。

| | 測った | 答え |
|---|---|---|
| 骨自身の**アニメ**回転 → 自身の position | v9/v10 | 運ばない |
| **親の**アニメ回転 → 子の position | v16 | 運ぶ |
| **親の**宣言回転** → 子の position | v14① | 運ぶ |
| **骨自身の宣言回転 → 自身の position** | ← ここ | **?** |

## 実測で分かったこと（，这一点は記録に値する）

**rig の出力と Bedrock のフレームは完全に一致した** — 横1本＋縦2本、左右の配置も一致。

つまり**回転が骨に適用されることは両クライアントで同じ**と確認できた。

## なぜ決着にならないのか

**この rig が問うたのは「回転が position を運ぶか」であって、「回転が効くか」ではない。**
質問文を後者に書いてしまった。**v12 と同じ間違い**（v12 も「上から2本目」という指示が
成立しなかった）。

**韻を当作するな。** 上の表の「?」はまだ「?」のままで、v19 はそれを埋めていない。

## 教訓（本セッションで rig を 4 本作り直した）

| rig | 壊れた理由 |
|---|---|
| v12 | 順序で指示した → その読みだと指示が成立しない |
| v14 / v15 | 三人称カメラに深度を読ませた／形だけ変えた |
| **v19** | **質問文と rig が別のことを聞いていた** |

**共通点: 質問が 2 つの候補のどちらでも成立しうる形でなかった。**
**唯一成功した rig（v16）は「答えが上下か左右か」だけで決まるようにしていた**（深度を排除）。

**次に probe を作るときは rig を先に作らない。先に質問文を書いて確認を取ること。**
